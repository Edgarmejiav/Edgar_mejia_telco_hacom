Objetivo:

Realizar una aplicación Angular 11 utilizando las siguientes tecnologías:

  • Bootstrap o Angular Material
  • Apache Echarts

Tecnologías Usadas:

Frontend:
  • Angular 11
  • Bootstrap
  • Angular Material
  • Apache Echarts para los gráficos
Backend (opcional) No Implementado
  • En lugar de Spring Boot WebFlux, se utilizó json-server local para pruebas y simulación de datos.

Requerimientos:

  1. Backend con Spring Boot WebFlux (opcional):

    Desarrollar un Web Service usando Spring Boot WebFlux en Java para alimentar la información de la web.

  2. Página Principal y CRUD de Libros:

    Se deben manejar las siguientes entidades:

    • Libro: ID, título, descripción, año, id autor, publicado, Fecha Registro
    • Autor: ID, Nombre, Género

    La aplicación debe permitir realizar operaciones CRUD para gestionar los libros y autores. La información se almacena en una base de datos.

  3. Dashboard:

    Se debe mostrar un resumen de los libros relacionados con el CRUD de libros. Incluir:

    • Gráfico de barras de libros por año.
    • Gráfico de Pie que muestre libros publicados y no publicados.
    • Gráfico de Pie que muestre la distribución de géneros de los autores.

    Detalles: Gráfico de línea que simule registros de 4,000 a 12,000 registros cada 5 segundos. Esta simulación debe eliminar información de más de 2 horas.

  4. Características adicionales:
    • Mantener la información de sesión y la ruta al presionar F5.
    • Utilizar directivas para gráficos con URL incorrecta y fechas con formato incorrecto.
    • Manejar los errores HTTP y mostrar mensajes de error globalmente.
  5. Repositorio en GitHub:

    Subir la aplicación a un repositorio público en GitHub y compartir el enlace al correo: alan.honorio@selectum.pe.
